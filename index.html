📖 員工操作手冊
好洺餐飲事業有限公司 員工APP操作SOP　v3.1.0
📱 介面導覽（新版）
打開APP會看到首頁九宮格，所有功能都在這裡，圖示加大好點選：
⏰打卡（綠色，最常用）· 📅班表 · 📝請假 · 🗓劃休 · 💰薪資 · 🔄換班 · 🛎️補打卡 · 📖操作手冊 · 👤我的
底部固定四個最常用：🏠首頁 ⏰打卡 📅班表 👤我的，隨時一鍵切換。
任何頁面想回首頁，按底部 🏠首頁 即可。
一、首次登入
Step 1　輸入帳號（您的員工工號，9碼數字）
Step 2　輸入預設密碼：工號 + aa（如 115041401aa）
Step 3　勾選「☑ 記住我」，下次自動登入
Step 4　系統會提醒修改密碼，請立即修改
密碼規則：8~16字元，必須含英文和數字
二、每日打卡
【離線打卡】
網路不穩時仍可正常打卡，紀錄暫存手機
恢復網路後自動上傳（畫面顯示「📡 X筆待同步」）
【補打卡申請】
忘記打卡時 → ⏰打卡頁下方「📋 補打卡申請」
填寫日期/時間/類型/原因 → 📤提交 → 等待店長審核
審核結果可在「近期申請」查看
【交接事項】
上班時🏠首頁會顯示店長留的今日交接事項（黃色卡片）
【帳號驗證】
首次登入會自動綁定手機，之後只有這支手機能打卡
更換手機需聯繫店長或老闆解除綁定

上班打卡
• 點「⏰ 打卡」→ 選擇打卡門市（總公司/交大店/台積電店）→ 按「☀ 上班」
• 打卡前必須選擇門市，GPS 會驗證您是否在該門市範圍內
• 門市範圍：總公司 100m / 交大店 200m / 台積電店 1000m
• 未選門市或不在範圍內 → 無法打卡
• 必須選擇打卡門市 + GPS 定位驗證（需在該門市範圍內）
• 打卡後會顯示今日注意事項
• 台積電店：請確認已放置手機/3C 產品

下班打卡
• 按「🌙 下班」→ GPS + PIN 驗證
• 系統自動跳出安全確認清單：
　✓ 水、電、瓦斯是否關閉
　✓ 冰箱溫度是否填寫
　✓ 門、窗、保全是否上鎖

外出/外出返回
• 外出辦事按「🚶 外出」，回來按「🏢 外出返回」
三、查看班表 / 換班申請
【休息日加班】
若店長將某日排為「休息日加班」，班表該日會顯示 🌙休息日加班 與時段；當日工時依勞基法休息日費率計薪（前2h×1.34／3-8h×1.67／9-12h×2.67），由管理端結算。
【換班申請】
📅班表頁 → 🔄換班申請 → 選擇日期/對象/原因 → 提交 → 等待店長審核
核准後系統自動交換兩人班次
• 點「📅 班表」查看個人當月排班
• 顯示每日上下班時間、休假日
• 國定假日、例假以不同顏色標示
四、劃休申請
Step 1　每月 10日前 點「🗓 劃休」
Step 2　在日曆上點選下個月想休假的日期
Step 3　最多選擇 4天
Step 4　按「📤 提交劃休申請」
Step 5　等待店長審核（已核准/已拒絕）
注意　超過10日系統自動關閉劃休功能
被拒絕　可按「重新申請」重新選擇日期
五、請假申請
• 點「📝 請假」→ 選假別/日期/天數 → 提交
• 等待主管簽核

假別說明：
• 事假：全年≤14日，不給薪
• 病假：全年≤30日，半薪，10日內不扣考績
• 家庭照顧假：全年7日，可按小時請，不扣全勤
• 特休：依年資（6月=3天/1年=7天/2年=10天...）
• 補休：加班後申請，有到期日
• 生理假：每月1日，不扣全勤
六、查看薪資
【薪資通知】
發薪後🏠首頁會出現藍色通知卡片，顯示薪資摘要，點「✓已讀」關閉
• 點「💰 薪資」查看每月薪資明細
• 顯示：本薪+津貼+加班費-勞保-健保-所得稅=實發
• 發薪日：每月10日（遇假日提前）
• 🤝 若您有跨店支援(以時薪計酬)，薪資頁下方會另外顯示「跨店支援時薪」明細與小計（本店月薪之外的額外工資；勞健保不重複扣、所得稅併入主單）
• 🛒 叫貨：首頁點「叫貨」→ 系統自動帶出您門市的叫貨連結，按「立即叫貨」開啟；也可從各店清單選擇其他門市叫貨
七、修改密碼 / 忘記密碼
修改密碼
• 👤 我的 → 🔐 修改密碼
• 輸入舊密碼 → 新密碼 → 確認新密碼
• 規則：8~16字元，英文+數字

忘記密碼
• 登入畫面 → 「忘記密碼？」
• 輸入帳號（工號）+ 身分證字號驗證
• 系統重設密碼為：工號+aa
• 重設後請立即修改密碼
八、加班核准後選擇
加班核准後，APP首頁會出現選擇卡片：
• 💰 領加班費 → 計入當月薪資（前2h×1.33/第3h起×1.67）
• 🗓 換補休 → 產生補休時數，6個月內有效
• 到期未休完 → 自動轉為加班費
• 選擇後不可更改，請謹慎選擇
九、員工滿意度調查
老闆發起調查後，🏠首頁會出現紫色問卷卡片
5個項目各評1~5分 → 📤匿名提交
調查結果老闆可查看，不會顯示是誰填的
十、老闆/店長行動管理
老闆或店長帳號登入後，底部多出3個分頁：
📋 審核　假單/加班/換班/劃休/補打卡，一鍵核准或駁回
📊 出勤　今日打卡狀況+未打卡名單+歷史查詢
📈 報表　在職人數/平均出勤/特休餘額/遲到統計
不在電腦前也能即時處理
十一、補休及特休換薪
特休換薪
• 年度終結或離職時，未休完的特休可折算工資
• 計算方式：日薪 × 未休天數
• 系統自動計算，含在離職結算薪資中

補休換薪
• 補休有到期日（依勞基法規定）
• 到期未休完 → 自動轉為加班費發放
• 加班費標準：前2h×1.33 / 第3h起×1.67
💡 小提示
• 打卡需在門市 GPS 範圍內（200~300m）
• 遲到當月累計超過30分鐘扣全勤
• 連續曠職3天視為自動離職
• 工作滿4小時可申請員工餐（100元/餐，上限200元/天）
• 新人報到需提供半年內體檢報告
• 有問題請聯繫店長或人資部門
🗓 劃休申請
每月10日前提交下月休假，最多4天
